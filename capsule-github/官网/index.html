数据会上传吗？

没有账号，没有服务器。记录写在本机存储里，备份码由你自己保管

收费吗？有广告吗？

免费，无内购、无广告、无需注册

两个能同时装吗？

可以。包名不同，各存各的数据，互不干扰

以后更新要重装吗？

不用。新版本只换页面代码，本地数据原地保留

换手机怎么办？

长按应用图标导出备份码，在新手机上粘贴导入

装完没有自动记账？

先在系统设置里开通知使用权；小米机型还要开自启动，省电策略设为无限制
